How it works

  1. Describe the toolWrite a short config, or fill in the web form.
  2. Map the fieldsAI suggests, code verifies every path, an admin approves.
  3. One engine runs itFetches, pages, retries and normalises on a schedule.
  4. Everything in one placeUsers, devices and events, with health and alerts.

Features

Config, not code

A new tool is a YAML file or a web form. No restart, no deploy.

One common schema

Every source lands as users, devices or events, in one store.

Safe secrets

Encrypted vault; never in config, logs or Git.

Reliable by default

Retries after 1, 2 and 4 s, honours Retry-After, quarantines bad records.

Visible health and alerts

Status for every connection, with a Slack alert on repeated failure.

Token abuse detection

An unusual jump in data volume pauses the connection and raises an alert.
